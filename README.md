# H-odagawa Oatmeal

## How do I install these formulae?

`brew install h-odagawa/oatmeal/<formula>`

Or `brew tap h-odagawa/oatmeal` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "h-odagawa/oatmeal"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
